# Условие задачи
Написать программу, которая по введенной дате вычисляет, сколько дней осталось до конца месяца или года в соответствии с запросом пользователя.

 # Алгоритм и блок-схема

Инициализация:

Установить русскую локаль (setlocale).

Объявить массив days[12] с количеством дней в каждом месяце (по умолчанию для февраля — 28).

Объявить переменные: day, month, year (для даты) и choice (для выбора действия).

Ввод даты:

Запросить у пользователя ввод даты (день, месяц, год).

Проверить корректность формата ввода (должно быть введено 3 числа).

Валидация месяца:

Проверить, находится ли месяц в диапазоне от 1 до 12.

Проверка на високосный год:

Если год делится на 4 и не делится на 100, или делится на 400, изменить количество дней для февраля (days[1] = 29).

Валидация дня:

Проверить, что введенный день больше или равен 1 и не превышает максимальное количество дней в указанном месяце.

Запрос действия:

Вывести меню:

1 — дней до конца месяца;

2 — дней до конца года.

Считать choice и проверить корректность формата ввода.

Вычисление результата:

Вычислить базовый остаток дней до конца текущего месяца: result = days[month - 1] - day.

Если choice == 2 (до конца года): в цикле прибавить к result количество дней всех последующих месяцев (с month до 11 включительно).

Вывод результата:

Вывести соответствующее сообщение в зависимости от choice и подсчитанного result. Если choice не 1 и не 2 — вывести ошибку.

Конец

 # Реализация программы

    int day, month, year, choice;

    // Массив с количеством дней в месяцах (январь..декабрь)
    int days[12] = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };

    printf("Введите дату (день месяц год): ");
    if (scanf("%d %d %d", &day, &month, &year) != 3) {
        printf("Ошибка: неверный формат ввода!\n");
        return 1;
    }

    // Проверка корректности месяца
    if (month < 1 || month > 12) {
        printf("Ошибка: месяц должен быть от 1 до 12!\n");
        return 1;
    }

    // Проверка на високосный год
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        days[1] = 29;
    }

    // Проверка корректности дня
    if (day < 1 || day > days[month - 1]) {
        printf("Ошибка: в месяце %d всего %d дней!\n", month, days[month - 1]);
        return 1;
    }

    // Меню выбора
    printf("\nЧто вычислить?\n");
    printf("  1 - дней до конца месяца\n");
    printf("  2 - дней до конца года\n");
    printf("Ваш выбор: ");
    if (scanf("%d", &choice) != 1) {
        printf("Ошибка: неверный формат ввода!\n");
        return 1;
    }

    // Базовый расчет: сколько дней осталось до конца текущего месяца
    int result = days[month - 1] - day;   

    if (choice == 2) {
        // Если нужен остаток до конца года, прибавляем дни последующих месяцев
        for (int m = month; m < 12; m++) {
            result += days[m];
        }
        printf("\nДо конца года осталось: %d дн.\n", result);
    }
    else if (choice == 1) {
        printf("\nДо конца месяца осталось: %d дн.\n", result);
    }
    else {
        printf("\nОшибка: выбор должен быть 1 или 2!\n");
        return 1;
    }

    return 0;
}

# Условие задачи
Написать программу, которая определяет, принадлежит ли точка с координатами 
(x,y)(x,y) заштрихованной области на координатной плоскости. Область представляет собой левую половину круга радиуса 3 с центром в начале координат (при x≤0x≤0).

#  Алгоритм и блок-схема

Инициализация:

Установить русскую локаль (setlocale).

Объявить переменные x и y типа double для хранения координат.

Ввод данных:

Запросить у пользователя ввод координат точки (x y).

Проверить корректность формата ввода (должно быть введено 2 числа).

Проверка условия принадлежности:

Проверить, лежит ли точка внутри или на границе области.

Вывод результата:

Если условие выполняется (Истина), вывести сообщение о том, что точка принадлежит области.

Иначе (Ложь), вывести сообщение о том, что точка не принадлежит области.

int main() {
    setlocale(LC_ALL, "Russian");

    double x, y;

    printf("Введите координаты точки (x y): ");
    if (scanf("%lf %lf", &x, &y) != 2) {
        printf("Ошибка: неверный формат ввода!\n");
        return 1;
    }

    // Проверка: точка должна быть слева от оси Y (x <= 0) 
    // И находиться внутри или на границе круга радиусом 3 (x^2 + y^2 <= 3^2)
    if (x <= 0 && (x * x + y * y) <= 9.0) {
        printf("\nТочка (%.2lf; %.2lf) принадлежит области.\n", x, y);
    }
    else {
        printf("\nТочка (%.2lf; %.2lf) НЕ принадлежит области.\n", x, y);
    }

    return 0;
}
